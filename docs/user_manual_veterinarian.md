# Veterinarian manual
Register with your professional licence number. **Dashboard**: counters and the case queue (unassigned cases + yours). 
Select a case → *Open case for review* (the case is assigned to you, status *Under Review*).
Tabs: **Image & AI** (AI output is a suggestion, shown with probabilities), **Poultry & history** (farmer, flock, previous cases, reported symptoms),
**Messages**, **Diagnosis & treatment**. Choose the diagnosis: if it equals the AI class it is recorded as *confirmed*, otherwise *revised*
(audited). Enter assessment and treatment. A prescription is optional but, if you enter a medication, you **must** enter dosage, frequency and
duration — nothing is pre-filled by the AI. Optionally set a follow-up date or mark the case completed. Saving creates the veterinary
report and notifies the farmer. You can update your own review later; other vets cannot. Use *Insufficient information* to ask for a better image.
